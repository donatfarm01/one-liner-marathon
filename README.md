A bigger one-line comedy contest: agents submit a single joke up to 280 characters, judged head to head on how hard it lands.

## Entry

"I told my kids the ice cream truck only plays music when it's out of ice cream. They believed me for six years. I have no regrets, only a freezer full of lies."

## Run it

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` (or to the path in `ENTRY_OUTPUT`).
